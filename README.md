# 全光院区网络课程：从原理到建设方案

> 面向**医院新楼建设**的全光园区网络（POL / F5G）自学课程。9 课，3 周，每课 45 分钟，最终产出可提交的《新楼全光网络建设方案》。

课程主页（**从这里开始**）：打开 **[`index.html`](./index.html)**——所有页面都可从这里进入，每页也能返回主页。

---

## 这是什么

一份从零到"能参与并主导方案设计"的全光网络学习材料：

- **知识**来自一手资料：ITU-T 标准（G.984 / G.9807.1 / G.671 / G.652 / G.988）、中国《无源光局域网工程技术标准》T/CECA 20002-2019、厂商白皮书与第三方分析（Omdia）。
- **技能**通过每课的测验 + 回忆练习建立即时反馈。
- **交付物**是第 9 课的《新楼全光网络建设方案》可填写模板（含两组练习数据）。

## 快速开始

1. 用浏览器打开 [`index.html`](./index.html)（无需服务器、无需联网）。
2. 按 Lesson 01 → 09 顺序学习。
3. 每课：读知识 → 做测验/回忆练习 → 看速查表复习 → 读中英对照双语 PDF。

## 课程路线图（9 课）

| 周 | 课 | 主题 | 本课成果 |
|---|---|---|---|
| 一 · 原理 | 01 | 全光院区：把三层压成两层 | 讲清 POL vs 三层以太网，判断区域适配性 |
| | 02 | ODN 与光功率预算 | 算出分光比并判断点位能否开通 |
| | 03 | PON 制式与选型 | 选出 GPON / XGS-PON / 50G-PON 并说明理由 |
| 二 · 设计 | 04 | 分层与拓扑 | 画出院区级 OLT + ODN 拓扑 |
| | 05 | 医院场景设计 | 产出行/门诊/手术/影像/物联网的分区设计 |
| | 06 | 可靠性与运维 | 制定可靠性方案与运维要点清单 |
| 三 · 落地 | 07 | OLT/ONU 与业务模型 | 读懂一张 OLT 业务配置模型图 |
| | 08 | 上手配置 | 完成 PON 口 + ONU 注册 + 业务 VLAN 端到端配置 |
| | 09 | 产出建设方案 | 产出《新楼全光网络建设方案》框架 |

## 目录结构

```
.
├── index.html                 # 课程主页（路线图导航页）★ 从这里开始
├── lessons/                   # 9 个课程页面（含动画演示）
├── reference/                 # 速查表（HTML）与中英对照双语 PDF
├── assets/                    # 共享样式与交互组件
│   ├── lesson.css             #   统一视觉样式
│   ├── quiz.js / recall.js    #   测验 / 回忆练习
│   ├── checklist.js           #   清单勾选（localStorage 记忆）
│   └── pon-flow.js            #   光信号可视化动画组件（自包含）
├── MISSION.md                 # 学习任务（为什么学 / 成功标准 / 边界）
├── RESOURCES.md               # 一手资料清单（含可信度标注与 Gaps）
├── GLOSSARY.md                # 术语基准（全课程统一的用词）
├── NOTES.md                   # 教学设计与工作笔记
└── learning-records/          # 学习记录（≈ 教学决策记录）
```

## 交互组件

- **光信号动画**（`assets/pon-flow.js`）：把"光脉冲"可视化，接入全部 9 课。
  - 例：Lesson 02 光功率预算动画显示脉冲沿途变暗并实时累计 dB；Lesson 04 保护倒换可点"故障点"切换主干/配线故障，对比 Type B 与 Type C。
- **测验 / 回忆练习 / 清单**：纯前端，无依赖。

## 团队使用

### 获取课程

```bash
git clone https://github.com/Ineocode/all-optical-network-course.git
cd all-optical-network-course
```

然后用浏览器打开 **`index.html`** 即可——纯静态，不需要服务器、不需要联网。

### 浏览与协作

- 本仓库为 **private**：团队成员需被邀请为 **Collaborator**（或克隆到本地查看）。
- 勘误、补充一手资料、改进动画：直接开 **Issue** 或提 **PR**。
- 新增课程：在 `lessons/` 下新建 `NNNN-*.html`，并在 `index.html` 的路线图里加一张卡片（模板可参考现有 lesson）。

### 三个常用入口

| 入口 | 路径 |
|---|---|
| 课程主页（路线图导航） | `index.html` |
| 课程正文 | `lessons/` |
| 速查表与双语 PDF | `reference/` |
