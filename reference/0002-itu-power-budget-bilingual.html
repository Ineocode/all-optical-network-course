A. ODN 的定义 / Definition of ODN — G.984.2 §3.2.3

optical distribution network (ODN): In the PON context, a tree of optical fibres in the access network, supplemented with power or wavelength splitters, filters or other passive optical devices.

光分配网（ODN）：在 PON 语境中，指接入网中的一棵光纤树，辅以功率分光器或波长分光器、滤波器，以及其他无源光器件。

C. 为什么是 B+ / Why class B+ — G.984.2 Annex A.1

The widespread interest in the 2.4 Gbit/s downstream, 1.2 Gbit/s upstream GPON system has provided increased visibility into the feasibility of loss budgets for this system.

对 2.4 Gbit/s 下行、1.2 Gbit/s 上行 GPON 系统的广泛关注，使人们对该系统损耗预算的可行性有了更清晰的认识。

This annex describes industry best practices for this rate combination.

本附件描述了针对这一速率组合的行业最佳实践。

The notable variations from the loss budgets found elsewhere in this Recommendation include: overall loss budgets midway between class B and class C; different value of optical path penalties; the OLT must support FEC in the downstream.

与本建议书其它部分给出的损耗预算相比，其显著差异包括：总体损耗预算介于 Class B 与 Class C 之间；光路代价取值不同；OLT 必须在下行方向支持 FEC（前向纠错）。

These variations can provide increased capabilities for operation of GPON systems.

这些差异可以提升 GPON 系统的运行能力。

Therefore, the budgets contained in this annex are recommended over and above all others in this Recommendation for the 2.4/1.2 Gbit/s rate PON.

因此，对于 2.4/1.2 Gbit/s 速率的 PON，本附件给出的预算优先于本建议书中的其它所有预算。

This budget is named B+.

这个预算被命名为 B+。

E. 分光器与无源器件损耗 / Splitter and passive component loss — G.671

Optical branching component (wavelength non-selective) for PONs: N × X where the number of input ports N = 1 or 2 and the number of output ports X = 2, 4, 8, 16, 32 or 64.

用于 PON 的光分支器件（波长非选择性）：N × X，其中输入端口数 N = 1 或 2，输出端口数 X = 2、4、8、16、32 或 64。

Branching component should comply with the insertion loss requirements for both WR1 and WR2.

分支器件应同时满足 WR1（1310 nm 窗口）与 WR2（1550 nm 窗口）两个波长范围的插入损耗要求。
