分层拓扑 & 保护方式速查

一手来源：ITU-T G.984.1 §14 · G.984.2 · G.671

01 OLT 部署模式

模式做法优点 / 代价
集中式全院区只在中心机房放 OLT机房好、运维集中；主干光缆用量大
分散式每栋楼/片区各放 OLT（或小容量 OLT）就近终结、省主干；机房多、运维分散
混合式中心机房大 OLT + 楼栋小 OLT平衡成本与运维，医院常见
决策因素说明
机房条件供电 / UPS / 空调 / 接地 / 安防——OLT 是有源设备
光缆路由主干从哪走、有无管道桥架
ODN 层级决定主干光纤用量与分光损耗
运维便利换板卡/查故障的到场成本
可靠性是否单点、能否双归核心、是否需 Type C

注意：ODN 可达 20 km，院内距离通常不是约束。

02 一级分光 vs 二级分光

一级分光（集中）二级分光（分散/级联）
结构OLT → 一个 1:N → ONU（并行）OLT → 1:M → 1:K → ONU（级联）
损耗最小（1:32 = 17.5 dB）略高（1:8+1:4 = 18.0 dB + 额外接续）
主干光纤用得多（从分光点拉 N 根）用得少（逐级下沉）
灵活性改动需动集中分光点可随楼层/楼栋逐级扩容
故障定位相对容易更复杂（多级无源）

原则：主干少分光、楼内就近分光；最终必须回 L2 光功率预算验证。ODN 形态为标准"树形与分支"结构（G.984.2）。

03 PON 保护类型（ITU-T G.984.1 §14.2）

类型双份范围可恢复范围切换
Type A仅光纤已废弃
Type BOLT 侧 + OLT 到分光器光纤；分光器 OLT 侧双输入口仅 OLT 侧冷备，切换期可能丢信号/丢帧
Type COLT 侧 + ONU 侧全双份任意一点热备，无损切换（hitless）
Type DB 与 C 混合已废弃
切换触发方式说明
自动切换故障触发：LOS 失光、LOF 失帧、信号劣化（BER 超阈值）
强制切换人工触发：光纤割接、更换

保护为可选功能（G.984.1 §14.3）。PON 线路终端可不在一台设备内，允许物理分离（双归属/dual parenting）。

04 医院保护选型建议

区域建议
手术室、影像中心（PACS/CT/MR）、数字病理、核心业务Type C
普通病房、门诊、办公Type B
后勤、仓库等非关键可不做 PON 侧保护，保留上行双归与双电源
端到端检查 PON 侧 Type B/C 之外，还要确认：OLT 上行双归核心、核心双机、OLT 双电源、主备走线物理分离。

05 画拓扑时自检清单

  1. OLT 位置：机房条件是否齐全？上行是否双归核心？
  2. ODN：一级还是二级？分光器放中心机房 / 楼栋 / 楼层？
  3. 光功率：分光比是否通过 L2 的损耗预算（含 3 dB 余量）？
  4. 带宽：Σ承诺带宽 ÷ 线路速率 的收敛比是否够用？
  5. 保护：关键区 Type C、普通区 Type B，是否还有单点？
  6. 走线：主备路径是否物理分离，不共管沟？
