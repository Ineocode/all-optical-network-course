一、ONU 激活 / Activation (§3.2.1)

activation: A set of distributed procedures executed by the optical line termination (OLT) and the optical network units (ONUs) that allows an inactive ONU to join or resume operations on the passive optical network (PON).

激活：由光线路终端（OLT）和光网络单元（ONU）共同执行的一组分布式过程，使一个未激活的 ONU 能够加入或恢复在 PON 上的运行。

The activation process includes three phases: parameter learning, serial number acquisition and ranging.

激活过程包含三个阶段：参数学习、序列号获取和测距。

二、带宽分配与 DBA / Bandwidth allocation & DBA (§3.2.2, §3.2.4)

bandwidth allocation: An upstream transmission opportunity granted by the OLT for the duration of the specified time interval to the specified traffic-bearing entity within an ONU.

带宽分配：OLT 在指定时间区间内，授予某个 ONU 内指定承载流量实体的一次上行发送机会。

dynamic bandwidth assignment (DBA): A process by which the OLT distributes the upstream PON capacity between the traffic-bearing entities within ONUs, based on the dynamic indication of their activity status and their configured traffic contracts.

动态带宽分配（DBA）：OLT 依据各 ONU 内承载流量实体的活动状态动态指示及其配置的流量合约，把上行 PON 容量在这些实体之间进行分配的过程。

三、GEM port 与 T-CONT / GEM port & T-CONT (§3.2.9, §3.2.25)

GEM port: An abstraction on the G-PON transmission convergence (GTC) adaptation sublayer representing a logical connection associated with a specific client packet flow.

GEM port：G-PON 传输汇聚（GTC）适配子层上的一个抽象，代表与某个特定客户端分组业务流相关联的逻辑连接。

transmission container (T-CONT): A traffic-bearing object within an ONU that represents a group of logical connections, is managed via the OMCC, and is treated as a single entity for the purpose of upstream bandwidth assignment on the PON.

传输容器（T-CONT）：ONU 内承载流量的对象，代表一组逻辑连接，经 OMCC 管理，并在 PON 上作为单一实体参与上行带宽分配。

四、Alloc-ID / Allocation identifier (§5.5.3)

Allocation identifier (Alloc-ID) is a 12-bit number that the OLT assigns to an ONU to identify a traffic-bearing entity that is a recipient of upstream bandwidth allocations within that ONU.

分配标识（Alloc-ID）是一个 12 位数字，由 OLT 分配给 ONU，用于标识该 ONU 内接收上行带宽分配的承载流量实体。

Such a traffic-bearing entity can be represented either by a T-CONT or by the upstream OMCC.

这样的承载流量实体既可以是 T-CONT，也可以是上行 OMCC。

Each ONU is assigned at least its default Alloc-ID, which is numerically equal to that ONU's ONU-ID, and may be assigned additional Alloc-IDs per the OLT's discretion.

每个 ONU 至少被分配一个默认 Alloc-ID，其数值等于该 ONU 的 ONU-ID；OLT 还可自行决定为其分配额外的 Alloc-ID。

The ONU's default Alloc-ID is assigned implicitly, by virtue of the ONU-ID assignment, and does not require an explicit Assign_Alloc-ID PLOAM message.

ONU 的默认 Alloc-ID 随 ONU-ID 的分配隐式分配，不需要显式的 Assign_Alloc-ID PLOAM 消息。

The default Alloc-ID is used to carry the upstream PLOAM and OMCC traffic and may carry user data traffic.

默认 Alloc-ID 用于承载上行 PLOAM 与 OMCC 流量，也可承载用户数据流量。

The default Alloc-ID cannot be de-allocated or changed using an Assign_Alloc-ID PLOAM message.

默认 Alloc-ID 不能被 Assign_Alloc-ID PLOAM 消息去分配或更改。

T-CONT type 1 is characterized by the fixed bandwidth component only, and is not eligible to share surplus bandwidth. It is suitable for carrying fixed-rate (or variable-rate with relatively low rate bound) traffic which is sensitive to delay and jitter.

T-CONT Type 1 只具有固定带宽成分，不具备共享剩余带宽的资格。适合承载对时延和抖动敏感、固定速率（或速率上限较低的变速）的业务。

T-CONT type 2 is characterized by the assured bandwidth only, and is not eligible to share surplus bandwidth. It is suitable for carrying on-off type traffic with well-defined rate bound which does not have strict delay and jitter requirements.

T-CONT Type 2 只具有保证带宽成分，不具备共享剩余带宽的资格。适合承载速率上限明确、对时延和抖动要求不严格的 on-off 型业务。

T-CONT type 3 is characterized by assured bandwidth and eligibility to participate in non-assured bandwidth sharing. It is suitable for carrying variable-rate bursty traffic which requires average rate guarantee.

T-CONT Type 3 具有保证带宽，并有资格参与非保证带宽的共享。适合承载需要平均速率保证的变速突发业务。

T-CONT type 4 is characterized by eligibility to share the Best-effort bandwidth with neither fixed nor assured bandwidth provisions. It is suitable for carrying variable-rate bursty traffic which does not exhibit delay sensitivity.

T-CONT Type 4 只具备共享尽力而为带宽的资格，既无固定也无保证带宽配置。适合承载对时延不敏感的变速突发业务。

Finally, T-CONT type 5 is a consolidation of other T-CONT types which can be applied to most general traffic flows.

最后，T-CONT Type 5 是其它类型的整合，可应用于大多数通用业务流。
