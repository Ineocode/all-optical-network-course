配套 Lesson 06 · 打印友好

可靠性 · 安全 · 运维速查

一手来源：ITU-T G.984.1 §14 · G.984.3 §12 + App. VI · G.988

01 可靠性五层

层次检查项
设备冗余OLT 双主控、双电源、关键板卡冗余
链路冗余Type B / Type C、双归属、核心交换机双机
电源双路市电 + UPS；ONU 侧 PoF / 本地备电
环境空调、防雷接地、主备走线物理分离
切换指标GPON 应支持 50 ms 保护时间（G.984.1 §14.3）

传统电话业务：丢帧超过 120 ms 会断话，需重新呼叫（G.984.1 §14.3）。案例：贵州省人民医院 50 ms 内切换。

02 PON 安全：威胁与对策

威胁说明
下行广播被窃听PON 下行广播给同口所有 ONU；恶意用户重编程 ONU 可监听他人下行（G.984.3 §12.1）
伪造 ONU 接入无认证时陌生 ONU 可能被误认上线
管理面盗用密码/注册 ID 泄漏后被冒充
对策标准做法
下行加密AES，CTR 模式，密钥 128 bit；密钥交换与定期切换（G.984.3 §12.2–12.4）
ONU 认证序列号（SN）/ PLOAM 密码 / 注册 ID（LOID）/ MAC 地址入库（G.984.3 App. VI）

03 管理与监测

能力靠什么
OLT 远程管理/配置 ONUOMCI（ITU-T G.988）：业务模板、属性、告警、性能
统一网管统一平台；最好与既有以太网同界面
光功率监测ONU 收光 / OLT 收光；分光器无源不可管 → 需 OTDR / 现场测光
告警LOS 失光、LOF 失帧、光功率越限、ONU 掉线

04 运维三阶段

阶段动作
开局规划（点位/分光比/预算）→ 施工（熔接/成端/标识）→ 验收（逐点测光功率 + 打业务）
日常监控告警 → 巡检光功率趋势 → 备份配置 → 维护 ONU 台账与认证白名单
故障看网管告警 → 判断 ONU/跳纤/ODN → 现场测光或 OTDR 定位 → 更换 → 复盘更新台账

05 方案自检清单

  1. 关键区是否 Type C、普通区 Type B？
  2. OLT 是否双电源、双主控、上行双归核心？
  3. 主备走线是否物理分离（不共管沟）？
  4. 下行 AES 加密是否开启并在验收中核对？
  5. ONU 是否全部认证（SN/密码/LOID），禁止即插即用？
  6. 是否有统一网管（OMCI）与光功率监测手段？
  7. 是否有 OTDR / 现场测光预案（分光器不可管）？
  8. 是否建立 ONU 台账与配置备份制度？
