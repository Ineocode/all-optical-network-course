医院场景设计速查：三张网 · 分区接入 · QoS

一手来源：Omdia《FTTO for hospitals》· 华为医疗方案

01 三张网与隔离强度

网络承载安全等级
内网（诊疗）HIS / EMR / PACS / LIS / 移动护理 / 医生站最高
外网（办公/互联网）OA / 邮件 / 互联网 / 患者与访客 Wi-Fi中
设备网（物联网）监护 / 楼控 / 门禁 / 资产定位 / 医疗设备高
隔离方式强度说明
VLAN 逻辑隔离弱同一物理网，配置错误可能越权
独立 ONU / 光纤中物理分开，但共享 OLT / ODN
TDM 硬隔离切片强同一张 PON 上划出独立管道，内网/外网/设备网硬隔离

02 分区接入设计

区域接什么设计要点
病房信息点/电话/电视/监护/呼叫/面板 AP一个 ONU 多业务；一纤到房间省约 80% 布线
门诊/诊室PC/打印/自助机/AP点位密；按楼层二级分光
手术室/示教4K 影像/术野摄像/示教直播低时延 + 零漫游 + Type C
影像科 (PACS/CT/MR)大文件上传/调阅1–10G，分光比 1:4–1:8，就近 ONU
数字病理/AI大切片上传 + AI 推理50G-PON；上传 129 s → 15 s
物联网/设备监护/门禁/楼控/资产/设备网口光 AP + 开放物联网；NearLink 亚米级定位

03 QoS 优先级

优先级业务诉求
最高医疗设备 / 语音呼叫 / 手术示教视频低时延、低抖动、不丢包
高内网诊疗系统稳定、可靠、带宽有保障
中办公 / 互联网尽力而为
低患者/访客 Wi-Fi / 后勤可被挤占

两个体验指标：零漫游（移动护理/手术不断网）、时延与带宽分开看（影像要大带宽、手术要低时延、访客要并发）。

05 分区设计自检清单

  1. 三张网（内网/外网/设备网）是否分清？
  2. 隔离方式是否与安全等级匹配（关键网用硬隔离切片）？
  3. 手术室/影像是否单独规划带宽与保护？
  4. 物联网/资产定位是否走独立设备网？
  5. QoS 是否分层，医疗设备与语音是否最高？
  6. 零漫游场景（移动护理、手术）是否确认支持？
  7. 每条业务是否都归到了某张网、某个 ONU、某个分光口？
