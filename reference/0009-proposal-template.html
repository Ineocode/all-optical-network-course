09 提交前自检清单

  1. 需求数据是否完整（点数/业务/带宽/距离/机房/可靠性）？
  2. 光功率预算是否含 1 dB 光路代价与 3 dB 余量？
  3. 分光比是否同时通过光功率门与带宽门？
  4. 制式选择是否给了理由（不是"厂商推荐"）？
  5. OLT 位置是否说明机房条件与双归？
  6. 关键区是否 Type C，普通区是否 Type B？
  7. 三张网隔离、AES、ONU 认证是否写明？
  8. 是否诚实列出全光的代价/边界与对策？
  9. 设备清单数量是否与点位/分光比/端口数自洽？
  10. 投资估算是否分区块、可否追溯到清单？
