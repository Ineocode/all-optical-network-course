华为 OLT（MA5800 / EA5800）配置命令速查

命令来自公开配置实例，务必以设备《命令参考》为准

免责与用法 型号/版本间命令语法有差异。本表用于理解流程与对象关系，实际配置前请对照设备文档。 参考：博客园《GPON 介绍及华为 OLT 网关注册配置流程》、简书《华为 OLT 业务配置》。

01 命令清单（按配置顺序）

步骤命令作用
登录enable / config提权、进全局配置模式
查硬件display board 0看板卡在位
进 PON 口interface gpon 0/1进入帧/槽对应的 PON 组
查端口display port state 0PON 口是否启用
找 ONUdisplay ont autofind 0列出未注册 ONU 及其 SN
DBA 模板dba-profile add profile-id 10 type4 max 1024000建上行带宽合约（type1–5）
线路模板ont-lineprofile gpon profile-id 10 profile-name …建 T-CONT / GEM 模板
— T-CONTtcont 1 dba-profile-id 10T-CONT 绑定 DBA
— GEMgem add 1 eth tcont 1GEM port 绑定 T-CONT
— 映射gem mapping 1 0 vlan 100用户 VLAN 映射到 GEM
— 提交commit / quit模板生效并退出
业务模板ont-srvprofile gpon profile-id 10 profile-name …定义 ONU 端口能力
— 端口ont-port eth 4 pots 14 个网口 + 1 个电话口
注册 ONUont add 0 0 sn-auth <SN> omci ont-lineprofile-id 10 ont-srvprofile-id 10 desc ward-101认证 SN、分配 ONU-ID 上线
备用认证ont add 0 0 password-auth <密码> always-on omci …用密码/注册 ID 认证
业务落地service-port vlan 100 gpon 0/1/0 ont 0 gemport 1 multi-service user-vlan 100 tag-transform translateGEM + VLAN 绑定
Native VLANont port native-vlan 0 0 eth 1 vlan 10 priority 0给 UNI 口配本地 VLAN
上行 VLANvlan 100 smart / port vlan 100 0/19 0核心侧放通业务 VLAN
保存save写入设备，重启不丢

02 验证 / 排错命令

命令看什么
display ont info 0 0ONU 运行状态、配置状态、光功率
display ont info by-sn <SN>按 SN 查 ONU 是否已注册
display service-port port 0/1/0 ont 0该 ONU 的业务流与 VLAN 映射
display ont-lineprofile gpon profile-id 10线路模板内容
undo service-port <index>删除某条业务流
interface gpon 0/1 → ont delete 0 0删除 ONU

03 命令 ↔ 业务模型对照

模型对象（L7）对应命令
ONU 身份（ONU-ID）ont add（sn-auth / password-auth）
上行带宽（T-CONT / Alloc-ID）dba-profile add + tcont
业务封装（GEM port）gem add + gem mapping
业务落地（service-port / VLAN）service-port + vlan / port vlan
ONU 端口能力ont-srvprofile + ont-port

04 配置完成自检清单

  1. PON 口启用、光功率正常（先于一切配置）
  2. DBA 模板已建，T-CONT 类型与业务匹配
  3. ont-lineprofile 已 commit，GEM 与 VLAN 映射正确
  4. ont-srvprofile 端口型号与实际 ONU 一致
  5. ONU 注册成功，display ont info 状态为 online
  6. service-port 已建，内外层 VLAN 转换方式正确
  7. 上行 VLAN 已在核心侧放通
  8. 已执行 save，并做过一次重启/断电验证
