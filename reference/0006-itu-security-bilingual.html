12 · 概述 / Security

This clause discusses the data security issues that PON raises.

本章讨论 PON 带来的数据安全问题。

It discusses the threat model that the security is intended to counter.

它讨论安全机制所要对抗的威胁模型。

It then discusses the basic key exchange and activation method.

随后讨论基本的密钥交换与激活方法。

12.1 · 基本威胁模型 / Basic threat model

The basic concern in PON is that the downstream data is broadcast to all ONUs attached to the PON.

PON 的基本隐患是：下行数据会广播给接入该 PON 的所有 ONU。

If a malicious user were to re-programme his ONU, then the malicious user could listen to all the downstream data of all the users.

如果恶意用户重新编程自己的 ONU，就能监听所有用户的下行数据。

It is this 'eavesdropping threat' that the PON security system is intended to counter.

PON 安全机制要对抗的正是这种"窃听威胁"。

Other, more exotic threats are not considered practically important because, in order to attempt these attacks, the user would have to expend more resources than it would be worth.

其他更"高级"的威胁被认为没有实际意义，因为发起这类攻击要耗费超过其收益的资源。

Furthermore, the PON itself has the unique property in that it is highly directional.

此外，PON 有一个独特性质：它具有很强的方向性。

So any ONU cannot observe the upstream traffic from the other ONUs on the PON.

因此，任何一个 ONU 都无法观察到同一 PON 上其他 ONU 的上行流量。

This allows privileged information (such as security keys) to be passed upstream in the clear.

这使得机密信息（例如安全密钥）可以以明文在上行方向传递。

While there are threats that could jeopardize this situation, such as an attacker tapping the common fibres of the PON, these again are not considered realistic, since the attacker would have to do so in public spaces, and would probably impair the very PON being tapped.

虽然存在威胁可能破坏这一前提（例如攻击者搭线窃听 PON 的公共光纤），但这同样被认为不现实：攻击者必须在公共空间操作，而且很可能把正在窃听的 PON 本身弄坏。

12.2 · 加密系统 / Encryption system

The encryption algorithm to be used is the advanced encryption standard (AES).

采用的加密算法是高级加密标准（AES）。

It is a block cipher that operates on 16-byte (128-bit) blocks of data.

它是一种分组密码，处理 16 字节（128 位）的数据块。

It accepts 128, 192 and 256 bit keys.

它可接受 128、192 和 256 位密钥。

This algorithm is described in documents published by the National Institute of Standards and Technology (NIST) in the United States of America.

该算法在美国国家标准与技术研究院（NIST）发布的文件中描述。

There are several modes of operation for this standard; however, only the 'counter' (CTR) mode shall be used.

该标准有多种工作模式，但只应使用"计数器"（CTR）模式。

The cipher generates a stream of 16-byte pseudo-random cipher blocks which are exclusive-OR'ed with the input clear-text to produce the output of cipher-text.

密码器生成一串 16 字节的伪随机密码块，与输入明文异或，得到输出密文。

The cipher-text is exclusive-OR'ed with the same pseudo-random cipher blocks to regenerate the clear-text.

密文再与相同的伪随机密码块异或，即可还原明文。

Also, the key length is fixed at 128 bits.

此外，密钥长度固定为 128 位。

Larger keys may be supported in the future, but this usage is currently unspecified.

未来可能支持更长的密钥，但当前该用法尚未规定。

附录 VI.1 · 基于序列号的认证 / Authentication by serial number

This method assumes that the association between the serial number (and, optionally, the PLOAM password) of the ONU and the specific subscriber is already established at the OLT either through pre-provisioning or in the course of previous activations.

该方法假定：ONU 的序列号（以及可选的 PLOAM 密码）与特定用户之间的关联，已通过预配置或此前激活过程在 OLT 上建立。

Because this method is the most straightforward in terms of PLOAM overhead, it is recommended for ONUs once their initial registration on the PON has been completed.

由于该方法在 PLOAM 开销上最直接，建议在 ONU 完成首次 PON 注册后采用。

In addition to the serial number, the PLOAM password, which is pre-provisioned (if fixed and known a priori) or learned at the previous activations (for example, if randomly generated), can be used for verification purposes.

除序列号外，PLOAM 密码也可用于验证：若固定且已知则预配置，若随机生成则在此前激活中学习获得。

附录 VI.2 · 基于 PLOAM 密码的认证 / Authentication by PLOAM password

This method assumes that a registration ID is assigned to a subscriber at the management level, and provisioned both into the OLT and communicated to installation or repair personnel or even to the subscriber directly.

该方法假定在管理层为用户分配一个注册 ID，并同时配置到 OLT、告知安装或维修人员，甚至直接告知用户。

There is a method for entering the registration ID into the ONU in the field.

存在一种在现场把注册 ID 录入 ONU 的方法。

Specification of such a method is beyond the scope of this Recommendation.

该方法的规范不属于本建议书的范围。

The registration ID populates the ONU's PLOAM password, which is used by the OLT to recognize the ONU.

注册 ID 会填入 ONU 的 PLOAM 密码，OLT 用它来识别 ONU。

The OLT may learn the value of the ONU's serial number for possible subsequent use in serial number based authentication.

OLT 可学习该 ONU 的序列号，以便后续用于基于序列号的认证。

附录 VI.3 · 其它认证方式 / Other forms of authentication

Additional ways to associate an ONU with a given subscriber, for example, the registration of the ONU's media access control (MAC) address in a database, are not precluded.

不排除其它将 ONU 与特定用户关联的方式，例如把 ONU 的媒体访问控制（MAC）地址登记到数据库。

However, such possibilities are beyond the scope of this Recommendation.

但这些可能性不属于本建议书的范围。
