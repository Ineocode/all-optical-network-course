分层与拓扑：OLT 放哪、ODN 怎么分、保护怎么做

2026-09-11 约 45 分钟 前置：Lesson 03

本课成果 · Win

你能画出院区级的 OLT + ODN 拓扑图：OLT 放在哪、分光器分几级、哪些链路做 Type B / Type C 保护，并说明每个选择的理由。

上一课结尾留了一个问题： 新楼的 OLT 该放住院楼、门诊楼，还是独立中心机房？ 这一课把这个问题连同"ODN 怎么分、哪里要保护"一起讲清楚——开始把方案画出来。

01 OLT 放哪：集中式、分散式，还是混合

先纠正一个直觉：距离几乎不是约束。ODN 是无源的，光纤可达 20 km [L1]， 院内几公里的跨度对它来说毫无压力。真正决定 OLT 位置的是下面这几件事：

决策因素为什么重要
机房条件OLT 是有源设备，要供电、UPS、空调、接地、安防——不是随便一个弱电间能放
光缆路由主干光缆从哪走、有没有管道/桥架，决定 OLT 到分光器的物理路径
ODN 分光层级OLT 越靠前，主干越集中；越靠近用户，主干光纤用量越少
运维便利换板卡、查故障要人到现场；OLT 集中则运维方便
可靠性OLT 是不是单点？能否双归属到核心？关键业务要不要 Type C

三种部署模式

模式做法优点 / 代价
集中式全院区只在中心机房放 OLT，ODN 拉遍各楼机房条件好、运维集中；主干光缆用量大、路由长
分散式每栋楼/每个片区各放一台 OLT（或小容量 OLT）就近终结、省主干光缆；机房点多、运维分散
混合式中心机房放大 OLT + 楼栋放小 OLT，上行统一汇聚平衡成本与运维，医院最常见
回到 L3 的问题 没有唯一正确答案，但有判断顺序：
① 新楼若有合格的设备间（供电/UPS/空调/安防）→ 可在新楼设备间放一台 OLT，就近接入、减少主干跳接；
② 若机房条件不足，或全院光缆本就汇聚到中心机房 → 集中放在中心机房；
③ 无论哪种，OLT 上行都应双归到核心交换机，不要让 OLT 成为单点。

02 ODN 怎么分：一级分光 vs 二级分光

标准里 ODN 的形态就是"点到多点的树形与分支结构" [G.984.2]。 工程上把它落成两种典型做法：

一级分光（集中分光）

OLT → 一个 1:N 分光器 → 各 ONU。
结构简单，损耗最小，故障定位相对容易；但分光器集中，需要从分光点拉出 N 根光纤，光纤用量大。

二级分光（分散分光）

OLT → 第一级 1:M → 第二级 1:K → ONU。
主干只用少量光纤，可随楼层/楼栋逐级分光；代价是多了插损和接续点，故障定位更复杂。

损耗差多少？用 L2 的分光器表算一下：

方案插入损耗说明
一级 1:3217.5 dBG.671 普通距离最大值
二级 1:8 + 1:410.6 + 7.4 = 18.0 dB比单级多约 0.5 dB，另有额外熔接/连接器损耗
选择要点 主干少分光、楼内就近分光是常见原则：主干（跨楼、长距离）用大分光比容易吃掉预算， 把分光器下沉到楼层/楼栋，既省光纤又保留灵活性。具体分几级、放哪里，必须回到 L2 的光功率预算去验证。

03 保护与冗余：Type B 和 Type C

PON 本来是一棵树，主干断了会连累一大片。ITU-T G.984.1 第 14 章定义了几种双份（duplex）保护配置 [G.984.1]：

类型双份的是什么能恢复到哪切换特性
Type A只双份光纤已废弃
Type BOLT 侧 + OLT 到分光器的光纤；分光器在 OLT 侧有两个输入口只能恢复 OLT 侧（ONU 侧不冗余）冷备；切换期间会丢信号甚至丢帧
Type COLT 侧 和 ONU 侧都双份任意一点故障都能切到备用热备；可实现无损切换（hitless）
Type DType B 与 C 的混合已废弃

来源：ITU-T G.984.1 (03/2008) 第 14.2 节。切换可由故障自动触发（LOS 失光、LOF 失帧、信号劣化 BER 超标）， 也可由人工强制触发（光纤割接、更换）。两种都要求是可选功能（14.3）。

把保护"跑"一遍。点左下"故障点"按钮，在 无 → OLT/主干 → 配线段 之间切换， 再切换 Type B / Type C，观察光脉冲走哪条路：

  • 主干故障：Type B 与 Type C 都能倒换到 OLT-B（都能恢复）。
  • 配线段故障（关键区别）：Type B 业务中断——它只保护 OLT 侧与主干， 保护不到 ONU 侧；而 Type C 倒换到备用配线，业务不断（图里 ONU 的第②个上行口）。
一句话记住区别

Type B 保的是"主干和 OLT"，Type C 保的是"从 OLT 到 ONU 全程"。 Type C 才敢说"任意一点断了业务不断"。

医院该怎么用

区域建议
手术室、影像中心（PACS/CT/MR）、数字病理、核心业务Type C（双 OLT/双板卡 + 双路径 + 双 ONU）
普通病房、门诊、办公Type B（或结合楼栋双上行）
后勤、仓库等非关键可不做 PON 侧保护，但保留 OLT 上行双归与双电源
别只盯 ODN 保护是端到端的：除了 PON 侧 Type B/C，还要看 OLT 上行是否双归核心、核心交换机是否双机、 OLT 是否双电源、主备走线是否物理分离。只做 PON 保护、上行仍是单链路，等于白做。

04 技能练习

回忆练习 · 画出院区拓扑

用一张纸，为下面的场景画出 OLT + ODN 拓扑，并标出保护方式。不用完美，关键是能把选择讲清楚：

场景：新院区一栋 20 层住院楼（每层约 100 个点位，含病房、护士站、Wi-Fi AP）， 另有独立的影像中心（CT/MR/PACS）和手术部。中心机房已在住院楼地下一层，条件齐全； 住院楼到影像中心约 500 m。

要回答：① OLT 放哪（几台、放哪里）？② ODN 用一级还是二级分光、分光器放哪？③ 哪些链路做 Type B、哪些做 Type C？

① OLT：中心机房条件齐全 → 在住院楼地下一层中心机房放主 OLT； 若影像中心点位多、光缆路由独立，可在影像中心设备间放一台小容量 OLT（混合式）， 两台上行都双归到核心交换机。

② ODN：住院楼采用二级分光——主干到楼层用 1:8，楼层内再用 1:4 到房间， 合起来 1:32（约 18.0 dB，回 L2 光功率预算验证）；影像中心点位少、带宽高，用一级 1:4–1:8 直连更简单、损耗更低。

③ 保护：手术部、影像中心（PACS）走 Type C（双 OLT/双板卡 + 双路径 + 双 ONU，任意点可恢复）； 普通病房与办公走 Type B（保 OLT 侧与主干）。所有 OLT 上行双归核心、双电源。

没有唯一标准答案；只要你的理由能对上"机房条件 / 省级光缆路由 / 光功率预算 / 故障影响范围"这几条，就是好方案。
