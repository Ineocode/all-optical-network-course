医院场景设计：三张网、五个区域、一套 QoS

2026-09-11 约 45 分钟 前置：Lesson 04

本课成果 · Win

你能产出一份医院全光网络的分区设计：把病房、门诊、手术室、影像、物联网分别用什么接、 走哪张网、怎么隔离、QoS 怎么排，一次讲清楚。

上一课画好了"骨架"（OLT、ODN、保护）。 这一课给它填上"血肉"：每个房间、每台设备怎么接，业务怎么分，安全怎么隔离。

01 先分三张网：内网 / 外网 / 设备网

医院网络复杂，不是因为它大，而是因为业务安全等级不同。 最实用的第一步，是把所有业务归到三张逻辑网里：

网络承载什么安全等级
内网（诊疗网）HIS、EMR、PACS/LIS、移动护理、医生站最高，涉及患者隐私与诊疗安全
外网（办公/互联网）OA、邮件、互联网、患者/访客 Wi-Fi中，可与互联网互通
设备网（物联网）监护、楼控、门禁、资产定位、医疗设备网口高，且设备多、协议杂

三种隔离方式，强度递增

方式做法强度
VLAN / 逻辑隔离同一张物理网上用 VLAN 分开弱：配置错误或攻击可能越权
独立 ONU/光纤不同网络用不同的 ONU 或光纤中：物理层面分开，但共享 OLT/ODN
硬隔离切片（TDM）在 PON 上用时分复用划出独立管道强：内网、外网、设备网在同一张网上做到硬隔离

华为医疗方案明确采用"基于 TDM 的硬管道（hard pipes），融合外网、内网与设备网，保障网络信息安全" [华为医疗方案]。

看三张网怎么走：默认 TDM 硬隔离（内网/外网/设备网各走独立管道）； 点按钮切成"仅 VLAN"，它们就共用同一条管道——风险也随之而来。

全光的额外好处 传统以太网里，三张网往往要三套交换机、三套布线；全光园区可以一张物理网 + 三种隔离承载， 这正是"一纤到房间、多种业务合一"的底气。

02 五个区域的接入设计

区域接什么设计要点
病房信息点、电话、电视、监护、呼叫、Wi-Fi 面板 AP一个 ONU 多业务下挂；一纤到房间，布线量可省约 80%
门诊 / 诊室PC、打印、自助机、AP点位密、业务杂；按楼层走二级分光
手术室 / 示教4K 影像、术野摄像、示教直播低时延 + 零漫游 + Type C 保护
影像科（PACS/CT/MR）大文件上传/调阅单点 1–10G，分光比 1:4–1:8，就近 ONU
数字病理 / AI大切片上传、AI 推理用 50G-PON + AI，上传 129 s → 15 s
物联网 / 设备监护、门禁、楼控、资产标签、医疗设备网口光 AP + 开放物联网；NearLink 亚米级资产定位
一个可以汇报的数字

传统铜缆网络读取 1000 张医学影像约需 30 秒；FTTO 全光网络可以降到 不到 1 秒。 这是"为什么要上全光"最直观的一句话 （Omdia 医院 FTTO 分析）。

03 QoS：把带宽和优先级排好

一张网上跑所有业务，就必须排优先级。医院里建议的顺序是：

优先级业务诉求
最高医疗设备、语音呼叫、手术/示教视频低时延、低抖动、不丢包
高内网诊疗系统（HIS/EMR/PACS）稳定、可靠、带宽有保障
中办公、互联网尽力而为
低患者/访客 Wi-Fi、后勤可被挤占

两个容易被忽略的体验指标

  • 零漫游（zero roaming）：移动护理车、手术示教设备在 AP 间移动时不断网—— 对需要连续连接的场景是刚需，选 ONU/光 AP 时要问清楚。
  • 时延 vs 带宽：影像要的是"大带宽"，手术要的是"低时延"，访客要的是"并发"。 三个诉求不同，不能用同一个分光比和同一种 QoS 模板打发。

04 两个真实案例（可写进汇报）

医院场景与成效
武汉协和医院质子治疗中心质子治疗的辐射要求线缆埋在厚混凝土里；若用铜缆，后续升级几乎无法换线。全光方案用光纤一次布放，避免了这个死结

05 技能练习

回忆练习 · 产出一份分区设计

针对"800 床新住院楼"，写出你的分区设计表（区域 / 接入方式 / 走哪张网 / 隔离方式 / QoS 优先级）。至少覆盖：病房、门诊、手术室、影像科、物联网。

病房：一个 ONU 多业务下挂信息点/电话/电视/监护 + 面板 AP → 内网 + 设备网 + 外网（访客 Wi-Fi）→ TDM 硬隔离切片 → 医疗设备/语音最高优先级。

门诊/诊室：ONU + PC/打印/自助机/AP → 内网 + 外网 → 硬隔离切片 → 诊疗系统高优先级、办公中优先级。

手术室/示教：独立 ONU + 光 AP，4K 视频 → 内网（示教可独立切片）→ Type C 保护 + 零漫游 → 最高优先级、低时延。

影像科：独立 ONU，10G 上行，分光比 1:4–1:8 → 内网 → 硬隔离切片 → 高优先级大带宽。

物联网：光 AP + 开放物联网/NearLink → 设备网 → 独立切片 → 中优先级；资产定位与设备管理走设备网，不占内网。

评判标准：三张网是否分清、关键区是否保护、QoS 是否分层、有没有把不同诉求的业务混在一条管道里。
