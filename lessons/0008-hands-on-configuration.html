上手配置：把六步变成命令

2026-09-11 约 45 分钟 前置：Lesson 07

本课成果 · Win

你能照着命令，在一台华为 OLT（MA5800 / EA5800）上完成一条端到端业务： PON 口 → 建模板 → 注册 ONU → 打 service-port → 放通 VLAN → 验证。

先看这条（很重要） 不同型号/软件版本的命令语法会有差异。本课目的是让你理解流程与对象关系， 命令以华为 MA5800/EA5800 系列为例，实际配置务必以你设备的《命令参考》为准。 本课命令来自公开的华为 OLT 配置实例（见页脚来源），可交叉验证，但不替代官方文档。

上一课给了六步模型。这一课用具体场景把它跑一遍。

01 场景与准备

项目取值（示例）
设备华为 MA5800 / EA5800（CLI 与 MA5680T 同族）
PON 口帧/槽/口 = 0/1，PON 端口号 0（即 0/1/0）
ONU 序列号（SN）4857544312345678（16 位十六进制，以实际为准）
业务病房内网，用户侧 VLAN 100，OLT 侧 VLAN 100
模板编号DBA / 线路 / 业务模板统一用 profile-id 10
上行口如 0/19/0（以你的上行板卡为准）

命名建议：模板用 hospital-line-100 这类带业务含义的名字，半年后你还能看懂。

02 动手：九步走完一条业务

  1. 登录并进入配置模式

    MA5800>enable
MA5800#config
MA5800(config)#

    enable 提权，config 进全局配置模式。后面所有命令都在 (config) 下。

  2. 确认板卡与 PON 口在位

    MA5800(config)#display board 0
MA5800(config)#interface gpon 0/1
MA5800(config-if-gpon-0/1)#display port state 0

    先确认业务板在位、PON 口已启用、光模块正常——光功率不通，后面全白配。

  3. 发现未注册的 ONU（拿到 SN）

    MA5800(config-if-gpon-0/1)#display ont autofind 0

    输出会列出该 PON 口下等待注册的 ONU 及其 SN。抄下你要注册的那一台。

  4. 建 DBA 模板（上行带宽合约）

    MA5800(config)#dba-profile add profile-id 10 type4 max 1024000
# type4 = 尽力而为共享；max 1024000 kbit/s ≈ 1G。索引 1–9 系统保留，从 10 起用。

    对应 L7 的 T-CONT 类型：语音/监护可选 type1/2，普通业务 type4 即可。

  5. 建线路模板（T-CONT + GEM，管上行与封装）

    MA5800(config)#ont-lineprofile gpon profile-id 10 profile-name hospital-line-100
MA5800(config-gpon-lineprofile-10)#tcont 1 dba-profile-id 10
MA5800(config-gpon-lineprofile-10)#gem add 1 eth tcont 1
MA5800(config-gpon-lineprofile-10)#gem mapping 1 0 vlan 100
MA5800(config-gpon-lineprofile-10)#commit
MA5800(config-gpon-lineprofile-10)#quit

    这里把 L7 的模型落成命令：T-CONT 绑 DBA（上行带宽）→ GEM port 绑 T-CONT（封装）→ GEM 映射 VLAN（业务流）。commit 后模板才生效。

  6. 建业务模板（ONU 端口能力）

    MA5800(config)#ont-srvprofile gpon profile-id 10 profile-name hospital-srv
MA5800(config-gpon-srvprofile-10)#ont-port eth 4 pots 1
MA5800(config-gpon-srvprofile-10)#commit
MA5800(config-gpon-srvprofile-10)#quit

    告诉系统这台 ONU 有 4 个网口、1 个电话口（按实际型号配）。

  7. 注册 ONU（让它拿到 ONU-ID 上线）

    MA5800(config)#interface gpon 0/1
MA5800(config-if-gpon-0/1)#ont add 0 0 sn-auth 4857544312345678 omci ont-lineprofile-id 10 ont-srvprofile-id 10 desc ward-101
# 语法：ont add <PON口> <ONU-ID> sn-auth <SN> omci ont-lineprofile-id <x> ont-srvprofile-id <y> desc <别名>
# 也可用密码认证：ont add 0 0 password-auth <密码> always-on omci ont-lineprofile-id 10 ont-srvprofile-id 10 desc ward-101

    对应 L7 的激活：认证 SN → 分配 ONU-ID（这里指定为 0）上线。

  8. 打 service-port（业务落地，绑 GEM 与 VLAN）

    MA5800(config)#service-port vlan 100 gpon 0/1/0 ont 0 gemport 1 multi-service user-vlan 100 tag-transform translate
# vlan 100 = OLT 侧 VLAN；user-vlan 100 = ONU 用户侧 VLAN；translate = 内外 VLAN 转换

    这条命令把"ONU 的 GEM port 1"与"业务 VLAN"绑起来——业务到这里才真正通到 OLT 侧。

    语法提醒部分版本需要显式写 service-port 索引；请对照你设备的命令参考。

  9. 放通上行 VLAN，并保存

    MA5800(config)#vlan 100 smart
MA5800(config)#port vlan 100 0/19 0
# 0/19 为上行口，以你的上行板卡为准
MA5800(config)#save
# commit 只让模板生效；save 才把配置写入设备，重启不丢

把配置顺序"跑"一遍（对照上面的九步命令）：每一步都会点亮一个配置对象， 它们按依赖关系依次建立：

03 验证：怎么确认真的通了

命令看什么
display ont info 0 0ONU 的 Run state、Config state、光功率是否正常
display service-port port 0/1/0 ont 0业务流是否建立、VLAN 映射是否正确
现场测光功率 / 打流ONU 收光在灵敏度之上；PC 能拿到网关、能 ping 通
命令 ↔ 模型对照（背这张表就够）

dba-profile / tcont → 上行带宽（T-CONT）　·　 gem add / gem mapping → 业务封装（GEM port）　·　 ont add → 身份（ONU-ID）　·　 service-port → 业务落地（GEM + VLAN）

04 新手最常踩的五个坑

现象常见原因
ONU 注册不上SN 抄错/大小写；认证方式与模板不匹配；光功率太低
模板改了不生效忘了 commit（模板内）或忘了 save（全局）
ONU 上线但业务不通service-port 没建；GEM / VLAN 映射对不上；用户侧 VLAN 与 OLT 侧没转换
能通一会儿就断光功率临界、或主备切换配置未生效
重启后配置丢了只 commit 没 save

05 技能练习

回忆练习 · 写出命令顺序

不看上面，按顺序写出"注册一台 ONU 并开通一条内网业务"的关键命令（写命令名 + 一句话作用即可）：

① display ont autofind 0 — 找到未注册 ONU 的 SN；
② dba-profile add … type4 max … — 建上行带宽合约；
③ ont-lineprofile … + tcont + gem add + gem mapping + commit — 建 T-CONT/GEM/VLAN 映射；
④ ont-srvprofile … + ont-port eth … + commit — 定义 ONU 端口能力；
⑤ ont add 0 0 sn-auth <SN> omci ont-lineprofile-id 10 ont-srvprofile-id 10 desc … — 注册 ONU；
⑥ service-port vlan 100 gpon 0/1/0 ont 0 gemport 1 multi-service user-vlan 100 tag-transform translate — 业务落地；
⑦ vlan 100 smart + port vlan 100 0/19 0 — 放通上行 VLAN；
⑧ save — 保存；
⑨ display ont info 0 0 / display service-port port 0/1/0 ont 0 — 验证。
