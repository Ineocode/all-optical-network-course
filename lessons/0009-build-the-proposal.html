产出建设方案：把九课所学装订成一份可提交的文件

2026-09-11 约 45 分钟 + 练习 前置：Lesson 01–08

本课成果 · Win

你能产出一份《新楼全光网络建设方案》的完整框架与摘要， 并用两组不同的项目数据各练一遍——从需求一路推到选型、拓扑、保护和投资。

前八课分别解决了"为什么、能不能通、选什么、怎么连、接什么、稳不稳、怎么配、怎么落"。 最后一课只做一件事：把它们组织成一份别人能看懂、能评审、能据此采购的方案。

01 方案不是作文：它是一条"数据流水线"

工程方案的核心不是文采，而是每个结论都能回溯到一组输入数据。把这条流水线跑通，方案自然就出来了：

从需求到方案的六道工序
① 需求
点数、建筑、业务、距离、机房条件、可靠性要求　输入：现场调研
↓
② 光功率
固定损耗 + 分光器 + 余量 ≤ 预算 → 分光比上限　L2
↓
③ 带宽
Σ承诺带宽 ÷ 线路速率 = 收敛比 → 过带宽门　L3
↓
④ 拓扑
OLT 放哪、一级/二级分光、保护方式　L4
↓
⑤ 场景
三张网、分区接入、隔离与 QoS　L5
↓
⑥ 落地
安全/运维方案 + 设备清单 + 投资估算　L6 · L8

把这条流水线"跑"一遍：每一道工序的输出就是下一道工序的输入， 任何一步算错，后面的选型、清单、投资都会跟着错：

评审最常问的三个问题 "分光比为什么是 1:32？""为什么选 XGS-PON 不选 GPON？""关键业务断了怎么办？" ——分别在②③④里，用数字回答。

02 方案目录模板（照着填）

章节写什么数据来源
1 项目概述建设背景、范围（哪栋楼/多少点）、目标需求调研
2 需求分析点位表、业务类型、带宽需求、距离、机房条件、可靠性等级①
3 设计依据引用标准：T/CECA 20002-2019、ITU-T G.984/G.9807.1/G.671、GB 相关规范RESOURCES
4 总体架构OLT-ODN-ONU 两层架构、与既有网络/核心的衔接L1 · L4
5 制式与选型GPON/XGS-PON/50G-PON 选择及理由；分光比；带宽账②③
6 光缆与 ODN一/二级分光、分光器位置、光纤路由、光功率预算表L2 · L4
7 场景设计病房/门诊/手术/影像/物联网接入；三张网与隔离；QoSL5
8 可靠性与安全Type B/C、双归属、双电源；ONU 认证、AES、网管L6
9 运维与验收网管方案、光功率监测、验收标准与测试项、运维流程L6 · L8
10 设备材料清单OLT/ONU/分光器/光缆/ODF 数量与规格由④⑤汇总
11 投资估算清单数量 × 单价；分区块汇总（可含 O&M 与搬迁）采购询价
12 实施计划分期、割接方案、培训、风险项目管理
写作三原则 ① 用数字说话：不写"带宽充足"，写"每点承诺 100M，收敛比 0.32"；
② 每个选择给理由：制式、分光比、保护方式都要有依据；
③ 诚实列代价：ONU 要供电、分光器不可管、老区改造贵——把边界写清楚，方案才可信。

03 两组项目数据（练手用）

下面两组数据刻意做成两类典型决策：A 是"预算敏感、普通业务"，B 是"高规格、关键业务"。 先自己做 A，再看参考；再做 B。

项目 A · 专科楼（12 层，预算敏感）

参数取值
建筑与点位12 层，每层约 100 个信息点，共 1200 点
业务办公、普通病房、门诊；无大型影像 / AI
单点承诺带宽约 100M
到中心机房距离主干 0.8 km，楼内有合格设备间
可靠性普通业务为主，Type B 即可
约束预算敏感，希望成熟、便宜

项目 B · 综合楼（20 层，高规格）

参数取值
建筑与点位20 层，每层约 150 点，共 3000 点
业务病房、门诊、手术部（4K 示教）、影像中心（PACS/CT/MR）、数字病理 AI、Wi-Fi 7 全覆盖
单点带宽普通 ≤100M；影像/手术 1–10G；Wi-Fi 7 AP 2.5–10G
到中心机房距离主干 2.0 km；楼内无现成合格机房
可靠性手术/影像/病理要 Type C，普通 Type B
约束面向未来 10 年，可接受较高投资

04 带练：项目 A 参考解答

  1. 光功率门（算分光比上限）

    光纤 0.8 km × 0.4 = 0.32 dB　熔接 2×0.3 = 0.6 dB
连接器 4×0.5 = 2.0 dB　　光路代价 1 dB　　余量 3 dB
固定合计 = 6.92 dB → B+ 28 − 6.92 = 21.08 dB 留给分光器
1:32(17.5) ✓ 舒适　|　1:64(20.9) ✓ 刚好

  2. 带宽门（选制式）

    # 若选 GPON 2.5G：1:32 → 32×100M = 3.2G > 2.5G → 收敛比 > 1 ✗
# 若选 XGS-PON 10G：1:32 → 3.2G / 10G = 0.32 ✓
1200 点 ÷ 32 ≈ 38 个 PON 口 → 38 × 10G = 380G ≥ 120G ✓

    结论：选 XGS-PON，分光比 1:32。GPON 在 100M/点 的承诺下过不了带宽门； 降到 50M/点 虽可勉强通过，但端口需求翻倍、未来无余量。

  3. 拓扑与保护

    楼内有合格设备间 → 在新楼设备间放 OLT，上行双归中心机房核心； ODN 楼内二级分光（楼层 1:4 + 楼栋 1:8 = 1:32）；普通业务 Type B。 每层约 4 个 PON 口（100÷32≈3.2）。

  4. 一句话结论（可写进摘要）

    新楼采用 XGS-PON 全光方案，1:32 分光，楼内设 OLT 并双归中心机房，普通业务 Type B 保护； 按每点 100M 承诺，收敛比 0.32，光功率预算余量充足（约 3.6 dB），满足未来十年带宽增长。

05 带练：项目 B 参考解答

  1. 分层选型（高规格的关键）

    区域制式分光比
    普通病房 / 门诊（约 2600 点）XGS-PON1:32
    影像 / 手术（约 200 点，1–10G）XGS-PON1:4 – 1:8
    数字病理 AI / Wi-Fi 7（约 50–100 点）50G-PON1:4

  2. 光功率门（2.0 km 主干）

    光纤 2.0 km × 0.4 = 0.8 dB　熔接 2×0.3 = 0.6 dB
连接器 4×0.5 = 2.0 dB　代价 1 dB　余量 3 dB
固定合计 = 7.4 dB → 28 − 7.4 = 20.6 dB
1:32(17.5) ✓　|　1:64(20.9) ✗（超 0.3 dB）

    所以普通区最多 1:32；影像区本就要求小分光比，两者不冲突。

  3. OLT 位置与保护

    3000 点、2.0 km 主干 → 在楼内新建合格设备间放 OLT，上行双归中心机房核心、双电源； 手术/影像/病理全程 Type C（双 OLT/双板卡 + 双路径 + 双 ONU），普通区 Type B。

  4. 一句话结论

    综合楼采用"XGS-PON 为主 + 50G-PON 承载影像与 AI"的混合架构： 普通区 1:32、影像/手术 1:4–1:8；楼内设 OLT 并双归核心；关键业务 Type C 全路径保护； 主干 2.0 km 下 1:32 仍满足光功率预算，支持 Wi-Fi 7 与数字病理等大带宽场景。

06 技能练习

结课练习 · 写出你的方案摘要

选 项目 A 或 B（强烈建议两个都做），写一段不超过 150 字的"方案摘要"，必须包含： 制式与理由、分光比、OLT 位置、保护方式、一个用数字支撑的结论。

摘要模板："本方案对【建筑/点位】采用【制式】全光网络，分光比【1:N】， 依据是【光功率预算余量 X dB + 收敛比 Y】；OLT 设于【位置】并双归核心； 对【关键区域】采用 Type C、其余 Type B；方案可支持【未来需求】，并已列出【代价/边界】及对策。"

评判标准：是否每个结论都有数字支撑、是否针对性回应了两组数据的不同约束（预算 vs 关键业务）。
