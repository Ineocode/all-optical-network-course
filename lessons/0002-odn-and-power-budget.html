ODN 与光功率预算：这条链路到底能不能通？

2026-09-11 约 45 分钟 前置：Lesson 01

本课成果 · Win

你能把一条真实链路的损耗**逐项加起来**，和光功率预算比较，判断某个分光比能不能用—— 并算出这条链路最多能做到 1:几。

上一课我们把网络压成了"OLT—无源 ODN—ONU"两层， 并用虚线画出了中间那一层。但虚线里到底装了什么？光从 OLT 出发，经过它会不会"越走越弱"到 ONU 收不到？ 这一课就把那层虚线拆开。

01 ODN 里到底装了什么

标准里的定义很干脆：ODN 是"接入网中的一棵光纤树，辅以功率分光器或波长分光器、滤波器， 以及其他无源光器件" [ITU-T G.984.2]。 落到工程上，你会在图纸上看到这几样东西：

器件作用有源 / 无源
单模光纤（G.652）传光；楼间主干 + 楼内垂直/水平无源
分光器（Splitter，1:N）把 OLT 一个 PON 口的光均分给 N 个 ONU无源（不供电）
连接器（跳纤 / 法兰）设备与光缆、ODF 之间的活动连接无源
熔接点（Splice）两段光缆永久接续无源
ODF（光纤配线架）光缆成端、调度、留纤无源
关键心智模型 ODN 是一个**纯损耗元件串起来的链条**。光每经过一个器件就弱一点； 链路能不能通，只看"总损耗"有没有超过"预算"。没有玄学，就是加法。

02 会"吃掉"光的四样东西（都有权威上限）

下面每个数值都来自 ITU-T 标准，做方案时按**最大值**算（最坏情况）：

① 光纤衰减 — G.652

波长G.652 最大衰减用途
1310 nm0.4 dB/kmPON 上行（ONU→OLT），损耗通常最大，是限制方向
1490 nm约 0.4 dB/km（1530–1565 nm 段最大 0.30）PON 下行（OLT→ONU）
1550 nm0.35 dB/km视频叠加 / 长距

来源：ITU-T G.652 (08/2024) 光纤衰减系数上限。

② 分光器插入损耗 — G.671

这是最容易被忽略、也最"吃预算"的一项。1×N 分光器在 1310 nm 窗口的最大插入损耗：

分光比1:21:41:81:161:321:64
最大 IL（dB，普通距离）3.97.410.614.117.520.9
最大 IL（dB，扩展距离）3.87.110.513.717.120.3

来源：ITU-T G.671 (11/2025) 第 6.6 节，PON 用无源分支器件。注意：分光比翻一倍，损耗大约**加 3 dB**。

③ 连接器 + ④ 熔接 — G.671

接续方式最大插入损耗
单芯活动连接器0.5 dB / 个
熔接（主动对准）0.3 dB / 点
熔接（被动对准）/ 机械接续0.5 dB / 点

来源：ITU-T G.671 (11/2025) 第 6.7、6.14 节。

还有两项"必须留"的

  • 光路代价（optical path penalty）：1 dB — G.984.2 规定的最大光路代价，直接计入预算。
  • 设计余量：3 dB — 给老化、温度、维修留的余量。不留余量的方案，验收时好看，三年后就会出问题。

03 光功率预算：把损耗相加，和预算比

先复习三条 dB 运算规则（你学过，但很容易在项目里算错）：

规则例子
串起来就相加0.5 dB 连接器 + 14.1 dB 分光器 = 14.6 dB
3 dB ≈ 功率减半分光比 1:2 → 少一半光
10 dB = 功率降到 1/101:32 约 17.5 dB，比 1/10 还少一半

预算（budget）本身也来自标准：它是"发送功率 − 接收灵敏度"，也就是这条链路**允许损失多少 dB**。 G.984.2 给出了 GPON 的等级：

等级允许损耗范围说明
ODN Class A5 – 20 dBODN 本身的衰减等级（G.982）
ODN Class B10 – 25 dB
ODN Class C15 – 30 dB
Class B+13 – 28 dBGPON 主流；最大损耗 28 dB
Class C+17 – 32 dB扩展距离，最大 60 km
Class D20 – 35 dB更长距离

来源：ITU-T G.984.2 (08/2019) 表 2a、附件 A（B+）、附录 V（C+/D）。XGS-PON 用另一套等级（N1/N2/E1/E2，见 G.9807.1），方法完全一样，算的时候用设备手册标称的预算值。

判定公式

总损耗 = 光纤 + 分光器 + 连接器 + 熔接 + 光路代价(1 dB) + 设计余量(3 dB)　≤　预算
成立 → 能开通；不成立 → 降分光比、减长度、换更高等级的光模块。

04 工作示例：新楼病房，最多能到 1:几？

场景（可替换成你的真实数字） 新楼 20 层病房楼。主机房（OLT）到新楼主干光缆 2.0 km，楼内到最远病房再 0.3 km。 主干有 2 个熔接点，全程 4 个活动连接器。按上行 1310 nm、Class B+（28 dB）算。

  1. 固定损耗（不含分光器）

    # 光纤  2.3 km × 0.4 dB/km        = 0.92 dB
# 熔接  2 点 × 0.3 dB            = 0.60 dB
# 连接器 4 个 × 0.5 dB          = 2.00 dB
# 光路代价 (G.984.2)          = 1.00 dB
# 设计余量 (自行预留)         = 3.00 dB
固定部分合计                 = 7.52 dB

  2. 还剩多少给分光器

    28 dB (Class B+ 预算) − 7.52 dB = 20.48 dB  ← 分光器能用的最大损耗

  3. 拿 G.671 的分光器损耗去比

    分光比分光器 IL是否 ≤ 20.48 dB结论
    1:1614.1 dB✓ 还剩 6.4 dB宽敞，推荐
    1:3217.5 dB✓ 还剩 3.0 dB刚好，可用
    1:6420.9 dB✗ 超 0.42 dB不可行
两个容易踩的坑 ① 上面的损耗都是 G.671 的最大值，实测链路通常更宽松；但设计必须按最坏情况算，否则验收时"个别房间通不了"。
② 一个 PON 口的光功率预算是整条 P2MP 链路共享的——离分光器最远、连接器最多的那个 ONU 决定这条线能不能过。

05 分光比还有第二张面孔：带宽

光功率只回答"能不能通"。分光比还决定另一件事：N 个 ONU 共享一个 PON 口的带宽—— 下行是广播，上行是时分复用（TDMA），同一时刻只有一个 ONU 能发。

所以 1:32 不只是"损耗够了"，还意味着 32 个病房/终端去分这个 PON 口的带宽。 这个"分光比 vs 带宽"的取舍是下一课的主题（见路线图）。现在只要记住： 选分光比，是要同时通过"光功率"和"带宽"两道门。

06 技能练习

先凭记忆作答，再回看上面的表。

回忆 + 计算练习

换一组数字，自己算一遍（不要翻上面）：

新楼到主机房 1.0 km 主干，楼内 0.2 km； 1 个熔接点、4 个活动连接器；上行 1310 nm、Class B+（28 dB）； 预留 3 dB 设计余量、计入 1 dB 光路代价。

问：① 固定损耗（含余量）是多少？② 留给分光器的预算还有多少？③ 1:16 和 1:32 哪个可行？

① 固定损耗：

光纤：1.2 km × 0.4 = 0.48 dB
熔接：1 × 0.3 = 0.30 dB
连接器：4 × 0.5 = 2.00 dB
光路代价：1.00 dB
设计余量：3.00 dB
合计 = 6.78 dB

② 留给分光器：28 − 6.78 = 21.22 dB

③ 结论：1:16（14.1 dB）和 1:32（17.5 dB）都小于 21.22 dB，两个都可行； 1:32 还剩约 3.7 dB 余量。如果想上 1:64（20.9 dB），也刚好能过，但余量只剩约 0.3 dB，风险高，不建议。
